# D3 评测集与核验方法

本目录包含20条问答对，L1、L2、L3、L4各5条，标注日期为2026-10-25。知识与来源范围限定为本项目2026-10-23采集的23篇资料，以及当前650字符、120字符重叠切分得到的202个分块。

## 文件

- `qa_set.jsonl`：正式问答数据，每行一个JSON对象，仅含作业要求的六个字段，UTF-8无BOM。
- `qa_evidence.jsonl`：逐题证据摘录、真实分块ID、原文链接、PDF页码、适用版本、来源哈希、分级理由和评分要点。
- `qa_set_核验与评分说明.md`：便于阅读的问题、参考答案、证据与L4评分表。
- `qa_manifest.json`：标注所绑定的语料、代码、依赖文件和分块内容哈希，以及数据文件哈希。
- `verify_eval_set.py`：仅用Python标准库校验数据结构、分层数量、分块存在性、证据摘录、原始文件哈希与绑定关系。

## 真实性与复核边界

参考答案与55处证据由助手逐条阅读本地资料后整理，不是直接采纳被测Qwen的回答。55处摘录均已核对：在标注分块中存在、在知识库原文中存在、在归档HTML或对应PDF页重新提取的文本中存在；归档文件哈希与来源记录一致。题目不要求模型预测不存在的数据，不编造推免名额、录取概率、薪资或官方培养要求。

涉及学生GPA、人数和个人目标的题目均明确为假设情境，用于检验规则应用和建议能力；不是声称确有这些学生或事件。L4建议的合理性属于评分判断，已与官方文件事实分开。公开课程页面不冒充完整校内教学大纲，历史政策不冒充现行政策。

**本集是大模型辅助编制并核验的标注成果，不冒称已经由教师、学生或其他独立人工审核。** 按作业对人工核对的要求，提交人应再逐题打开证据、确认答案和评分要点，并自行承担最终金标审核；可在独立复核后填写审核记录。归档哈希一致能证明本地文件一致性，不能替代官方最新有效性证明。本任务未重新抓取网站，评测以固定语料版本为准。

## 分层原则

| 等级 | 题号 | 实际能力 |
|---|---|---|
| L1 | q001—q005 | 明文事实，核心答案在单个片段中直接出现 |
| L2 | q006—q010 | 跨片段/跨文档整合、差额/合计计算与概念比较 |
| L3 | q011—q015 | 给定假设情境，依据文档明文条件推导结论，解释规则与应用过程 |
| L4 | q016—q020 | 无唯一决策规则的规划、专业匹配、学习设计与风险权衡，按有证据的要点评分 |

没有把“换一种说法询问同一数字”当作L2，也没有将“要求列出步骤”本身当成L3/L4。分级本身存在边界，可由课程教师复核。

## 校验

在项目根目录运行，不需要Ollama，不产生实验结果：

```cmd
python data\eval\verify_eval_set.py
```

可先用现有程序查看一次检索：

```cmd
python src\retrieve.py "根据云南大学《数据库概论》公开慕课课程大纲，该课程要求的先修课是什么？" --top-k 5
```

该脚本不调用生成模型，不计算答题正确率。现有 `src/evaluate.py` 仍是之前的开发定位检查，**不会自动对本评测集生成完整T1–T5结果**。这次只构建D3数据，不修改检索算法或补跑实验。

## 指标与评分

1. 作业给定的Recall@k口径：某题的 `gold_chunk_ids` 中至少一个被召回则记命中，最后计算命中题数/总题数。MRR使用首次命中真实gold chunk的排名倒数。不得用文档ID命中替代chunk命中。
2. 多证据题仅命中其中一个块，并不表示拿到了支持完整答案的全部证据。建议另报逐题gold块覆盖比例，区分“命中任一证据”与“完整证据覆盖”。
3. `gold_chunk_ids` 列的是此次标注的实际证据块，不声称已穷尽所有重叠片段。切分重叠可能产生内容等价片段，严格chunk评测会有边界，应检查失败案例，不能将等价片段一概视为完全无用。
4. L1–L3建议人工按0/1/2分：0=主要结论错误或虚构；1=结论部分正确但漏掉关键条件/推导；2=结论、条件和必要解释均正确。答案表述可不同，不能只做字符串完全匹配。
5. L4每题在 `qa_evidence.jsonl` 给出5个评分点，每点0或1分，共0—5分；不要求逐字复述gold_answer。事实错误影响对应得分，出现无依据的具体数字、资格保证等，另外记录为幻觉。
6. 引用忠实度单独核对：答案事实是否由实际召回块支持；gold有依据不代表模型此次真的检索到该依据。不要把同一个gold_answer同时当成自动裁判。

## 版本绑定

当前gold ID是实际索引产生的，例如 `ynu006_p000_00088`，不是自造占位编号。已从当前加载、切分代码重新得到202块，并逐块比较编号和文本，确认与标注索引一致。

若修改语料、来源顺序、分块参数或切分代码，应重建索引并重新核对gold ID与证据。相同ID不保证内容未变；校验器会同时校验内容与元数据摘要。改变T2分块配置时不能直接沿用本集旧的chunk ID计算Recall，应按证据原文/来源重新映射各配置的gold块。

本集部分基础事实与原有开发题重叠，可用于课程小规模验证，但不应声称是完全未见过的独立测试集，也不能用它调参后再声称无偏测试。未运行被测LLM来挑选“能答对的题”。
