# T8-1 幻觉治理实验

本包对应作业9.4.3：检索后、最终回答前执行证据审核，充分时生成、部分充分时限定回答、不充分时拒答。未提供课件，故这是按作业要求实现的简化实验，不声称复现RAG-HAT原算法。

## 安装位置与运行

将本文件夹整体上传到服务器的 /workspace/pgg/rag-project/ 中，与src、data同级。脚本调用现有基础索引，默认512字符/128重叠（实际以项目kb.py和索引为准），并非上一次T2的sliding_1024。两组保持同一检索、同一模型及相同生成参数；唯一干预是检测、门控和检测提示。

终端：

```bash
cd /workspace/pgg/rag-project
source .venv/bin/activate
ollama list
python T8-1实验包/run_t8_1.py --question-id q006 --output-dir results/t8_1_smoke
```

若Ollama未启动，先执行：

```bash
ollama serve > /workspace/pgg/ollama.log 2>&1 &
```

单题成功后运行正式20题：

```bash
python T8-1实验包/run_t8_1.py --output-dir results/t8_1
```

每题最多三次模型调用：原系统生成、证据检测、检测后生成；证据不足时第三次调用用固定的资料不足提示替代。输出逐题保存。中断后相同命令加 --resume 可接着运行；修改代码或输入后需要换新输出目录。不要将单题smoke结果混入正式20题结果。

## 结果

- paired_answers.jsonl：问题、参考答案、实际片段、两组原始回答、检测JSON、耗时、token数和结束原因。
- metadata.json：模型digest、脚本和输入哈希、生成参数。种子不保证不同平台完全一致。
- reviews.jsonl：事后逐题评分模板。每题before/after各一条。未标注为null，不能当作无幻觉。

原题集的答案不传给检测或生成。检测由同一个模型完成，并不代表检测一定可靠，也不是幻觉真值。模型输出资料不足只表示本次检索不足，不意味着相关政策不存在。

## 怎样评分

结合实际参考片段与已核实的源文件人工检查两组回答。回答中出现任何一处无依据、与资料冲突或适用对象/年份错误的事实性结论，将hallucination设为true，并在unsupported_quote中粘贴问题原句、reason中解释依据；否则为false。缺少要点不自动等于幻觉。建议应标明为建议，不因原文未逐字出现就直接判幻觉。完全拒答或未实质回答设refusal=true；部分回答是否有幻觉按实际事实判断，并在理由中说明。

score继续采用既有标准：L1–L3为0/1/2；L4按qa_evidence.jsonl的五个评分要点各0/1，point_scores填写五个整数，score为合计，max_score是2或5。reason必须写。不要因回答更长或措辞不同扣文字相似度分。普通JSON编辑器或JupyterLab文本编辑即可填写。保留实际评分人的信息在报告中。

填写示例（仅为格式，不是实际评分）：

```json
{"id":"q006","condition":"before","hallucination":false,"refusal":false,"score":2,"max_score":2,"point_scores":null,"reason":"这里写实际依据","unsupported_quote":""}
```

填完运行：

```bash
python T8-1实验包/summarize_t8_1.py --output-dir results/t8_1
```

生成summary.json和comparison.png。未填写评分、缺题或模型输出截断时脚本停止，避免发布不完整结果。

## 报告写法

主要指标：幻觉回答数/总题数。同时报告拒答率、非拒答中的幻觉率、归一化答案得分和包括检测在内的平均延迟。效果允许变差，不能先假定治理有效。20题每题对应5个百分点，只能作小样本观察。

图：问题→固定检索top5→证据审核→充分/部分充分/不足→限定生成/固定拒答。

对照同一问题展示至少一个改善案例和一个误判/未改善案例。明确检测与生成使用同一模型、增加调用和提示的干预，以及证据误判和过度拒答风险。原T1在不同参数下生成的旧答案不能直接冒充本次对照；本包重新运行两组得到可比较答案。若原题集尚未核实，应先核实再解释最终指标。
