## 先进入项目

在Anaconda Prompt中运行：

```cmd
cd /d D:\Desktop\学习资料\LLM-RAG\LLM-RAG
```

本次不需要重新运行40次实验才能补图。如果确实要重新跑完整对照，请使用新目录，保留旧输出：

## 图片插入方法

1. 截图只截终端或资料窗口，避免整张桌面，放大字体后再截图。
2. 建议截图宽度至少1200像素，横向裁切接近预留区域比例。
3. 在PowerPoint中删除“待插入运行截图”文字和虚线矩形，再插入截图。
4. 保持截图原始比例，不拉伸压扁。必要时拆分为两张图或只展示关键输出。
5. 标明“已有实验记录”或“新一次运行”及日期。不要制作模拟终端图来代替实际运行。

- 73.0%与25.5%是助手逐题核对后的归一化得分，不能改写为准确率。

- 所有题号以`qa_set.jsonl`与原始结果文件为准，不以调整过顺序的可读说明为准。
