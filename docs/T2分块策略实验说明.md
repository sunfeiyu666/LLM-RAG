# T2 分块策略实验说明

## 实验范围

脚本 `src/experiment_t2.py` 固定语料、TF-IDF/LSA 向量化、FAISS 检索器和 `top-k=5`，只改变分块策略。
默认运行以下 12 组配置：

- 固定长度：256、512、1024，重叠为 0；
- 滑动窗口：256、512、1024，重叠为 128；
- 语义分块：256、512、1024；
- Small-to-Big：用 256、512、1024 的小块检索，返回所属大块作为生成上下文。

语义分块先按中文句末标点和段落形成候选语义单元，再计算相邻单元的字符 TF-IDF 余弦相似度，优先在低相似度处断开，并用 `chunk_size` 约束目标长度。该实现不增加在线模型依赖，实验可复现。

## 运行方法

在项目根目录执行：

```powershell
conda activate rag-langchain
python src/experiment_t2.py
```

仓库尚无正式 `data/eval/qa_set.jsonl` 时，脚本会使用 `src/check_retrieval.py` 中的 20 条开发定位题，并在报告中标记为 `development_smoke_set`。该结果只用于检查流程，不能作为最终课程报告结果。

正式评测集加入后直接重新运行。若 Ollama 已启动且存在 `qwen3:4b-instruct`，使用以下命令生成答案并按标准答案计算 ROUGE-L F1：

```powershell
python src/experiment_t2.py --generate
```

调试单组配置：

```powershell
python src/experiment_t2.py --config semantic_512
```

## 输出

所有结果写入 `results/t2/`：

- 每组配置一个 JSONL，保存逐题 top-5、Recall@5、答案和耗时；
- `t2_summary.csv`：12 组汇总数据；
- `recall_at_5.png`、`answer_correctness.png`：对比图；
- `failure_case.json`：一个切分配置失败的案例及召回原文；
- `T2实验报告草稿.md`：可合并到课程报告的结果表和初步结论；
- `run_metadata.json`：本次实验配置。

## 与正式评测集的衔接

不同分块配置会产生不同的 `chunk_id`。因此正式评测集最好在作业规定字段外增加：

```json
{
  "gold_doc_ids": ["ynu001"],
  "gold_evidence": ["标准答案所在的原文证据"]
}
```

脚本会自动读取同目录的 `qa_evidence.jsonl`，把其中的 `quote` 和 `doc_id` 合并到正式题目。随后依次使用原文证据、精确 chunk ID、文档 ID判断检索命中，并把实际使用的依据写入 `recall_basis`。正式报告优先采用去除空白后的原文证据判断，以保证不同分块方法之间公平比较。
