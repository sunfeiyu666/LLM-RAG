# T5：BM25 候选池上的重排与自信息量压缩

正式评测集 20 题，2026-10-26 运行，共 20 × 3 种排序 × 压缩前后 = 120 条独立回答。T4 与 T5 使用同一份 `qa_set.jsonl` 和同一批 202 个知识库文本块。仓库保存代码与轻量实验结果；模型权重和索引需在复现时准备。

## 方法

T4 正式 Recall@k、MRR@10 最优的是 BM25，因此每题先取得同一份 **BM25 top-5**。直接组截取前 3；规则组按标题词项与政策年份调整这 5 块的顺序后取 3；模型组用本地 `BAAI/bge-reranker-base` Cross-Encoder 对 5 块打分后取 3。三组各自再做压缩前后配对，文本块编号保持不变。

压缩方法是基于词项自信息量的句子选择。对知识库 202 块统计词项出现频率 `df(t)`，用 `p(t)=(df(t)+1)/(202+1)`，`I(t)=-ln p(t)`；句子的得分为它与问题共享词项的 `I(t)` 之和。每块最多保留 4 个正分句，按原文顺序拼接。此次 180 个被压缩文本块中，没有触发无正分句的边界情况。Context token 使用本地 Qwen3-4B-Instruct-2507 tokenizer，对传给生成模型的完整 `format_context` 计数；不把问题、系统提示或重排模型的输入混入 Context token。

生成模型为 Ollama `qwen3:4b-instruct`，温度 0.2、种子 42、上下文 16384；模型设置见 `run_metadata.json`。准确性和引文支撑度各按 0—2 分逐题核对：2 为关键结论完整或引文直接支持，1 为部分正确或部分支持，0 为主结论错误或无有效支持。120 条答案、所选块、评分及理由分别见 `t5_full_rows.jsonl`、`t5_answer_review.csv`；评分与原始答案的绑定信息见 `quality_review_metadata.json`。这些是本项目的逐题判断，并非外部独立评测。

## 权衡结论

- **重排没有改善本组答案质量。** 不压缩时，规则组平均准确性 1.40，模型组 1.35，均低于直接组 1.55；规则组虽使全部证据@3 从 0.50 到 0.55，却把任一证据@3 从 1.00 降到 0.95。模型组进一步降到 0.90。q007、q008 中部分重排把另一份通知的关键块挤出 top-3；q006、q015 则展示规则组找到第八条而改善答案的正例。平均值并不代表每题都变差。
- **压缩约省一半 Context token，但有质量代价。** 直接组平均从 1332.10 减到 667.25（约 49.9%），端到端从 14.09 秒减到 9.66 秒，但准确性从 1.55 降至 1.35、引文支撑从 1.60 降至 1.35。规则组与模型组也分别出现 0.05、0.15 的准确性下降。因此，对要求精确政策条件和可追溯引用的问答，这组压缩设置不值得默认启用；若更重视 token 与响应时间，可作为明确允许质量下降的选项。
- **额外延迟需与质量一起看。** Cross-Encoder 排序阶段平均增加 1.38 秒/题，未压缩端到端比直接组慢约 0.71 秒/题，同时平均准确性下降 0.20。总耗时还受生成长度影响，所以额外重排开销以单独计时列为准；六个实际运行点的权衡曲线见 PNG。

## 复现与限制

安装 `requirements-t4-t5.txt`，准备 Ollama 的 `qwen3:4b-instruct`、`models/bge-reranker-base` 和 `models/qwen3-4b-instruct-2507-tokenizer` 后，在仓库根目录运行：

```powershell
python -B src/t5_evaluate.py --qa data/eval/qa_set.jsonl --out results/t5_reproduce --retrieval bm25 --dense-backend lsa --model-reranker cross_encoder --compression both --limit 20
```

`--dense-backend lsa` 是当前命令行参数，**BM25 检索不会调用稠密分支**。结果目录必须不存在，避免覆盖正式实验。模型权重不随仓库提交，评分只适用于这组课程题目，不宜外推到其他语料。
