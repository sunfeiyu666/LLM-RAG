## 结果解释与边界

MRR为0.875，MAP为0.739；Recall@3为100%，表示每题至少命中一个gold片段，全部gold平均覆盖为72.08%，不能解释为答案全对。字符ROUGE-L为0.248，上游准确性评分保留1.55/2的原量尺。

忠实度4.22/5、严格幻觉率50/213≈23.47%来自本轮Codex助手按实际前三片段及题设逐事实评估。部分支持也计入严格幻觉率；它不等于现实错误率或答错题目比例。评分不是独立人工标注，校验通过不代表语义判断没有主观性。

复用同学T5保存的20条实际回答，未重新生成。完整Context未在上游直接保存，本轮按冻结片段和原格式函数重建，逐题片段编号与正文字符数匹配；不能声称和当时原始Context字符串直接逐字核对过。token和耗时使用上游记录，未在本机重新测速；原停止原因也未保存。

T2记录中的答案正确性是检索证据代理值，未生成真实答案；T4/T5仍使用650字符、重叠120的202块。本目录没有把尚未运行验证的T2最佳分块或T3优化宣称为已整合系统。旧T7保留在相邻目录，配置及评分口径不同，不与新版混表。

本次实现与分析有大模型辅助；所有源版本、计算与评分依据公开，供组员复核。
