## 结果使用边界

T7复用的是T3保存的20条真实BM25回答和实际top-5 Context，没有重新生成答案。T7发现原自动评分存在误判，因此保留T3旧评分、新模型评分及公开的助手复核量表；报告中最终正确性4.30/5、忠实度约4.38/5、严格幻觉率26/169≈15.38%属于助手复核结果，并非独立人工标注。不同评分记录不能混用，也不能把评分纠错解释为系统性能改善。

原始生成配置的768 token上限导致4条长回答截断，报告明确保留这一失败。每级只有5题，结论限于此固定快照。改进建议尚未当作新方案实施并验证。
