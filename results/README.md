# 本地实验结果

本目录保存课程实验的代码输出和结果说明。模型权重、向量索引与虚拟环境不纳入 Git。

逐条对应课程要求的核对表见 [`T4_T5_要求核对.md`](T4_T5_要求核对.md)；可执行 `python results/verify_t4_t5.py` 复核交付文件。

## T1 基础对照

现存的 20 题基础 RAG 与无检索原始输出分别为 `t1_baseline.jsonl`、`t1_no_retrieval.jsonl`；`t1_summary.json`、`T1_基线与对照实验分析.md` 和 `t1_逐题答案对照.md` 提供汇总与案例。原先文档中列出的若干 T1 CSV、日志与校验文件在当前本地目录中不存在，因此此处不将它们列为交付文件。

## T4 检索策略对比

正式实验、指标表、PNG 图、原始 top-10 排序、5 条 BGE 优势诊断查询和 5 条 BM25 优势正式题，见 [`t4_1024_128_20261026/README.md`](t4_1024_128_20261026/README.md)。全部结果均来自 `1024/128` 分块的 147 个文本块。

## T5 重排与压缩

在 T4 正式指标最优的 BM25 top-5 上开展的完整实验，见 [`t5_1024_128_20261026/README.md`](t5_1024_128_20261026/README.md)。该目录与 T4 独立，包含完整的 120 条原始答案、逐题评分、Context token、延迟和 PNG 权衡图；压缩词项权重同样来自当前 147 个文本块。
