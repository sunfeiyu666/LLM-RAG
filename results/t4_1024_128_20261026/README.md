# T4：1024/128分块实验说明

本次正式实验统一采用1024/128分块，并建立对应的LangChain/FAISS索引和BGE/FAISS索引。23篇语料共得到147个文本块。20题评测集的问题、标准答案和证据原文保持不变，证据编号对应当前分块。

## 正式指标

| 检索器 | Recall@1 | Recall@3 | Recall@5 | Recall@10 | MRR@10 |
|---|---:|---:|---:|---:|---:|
| BM25 | 0.80 | 1.00 | 1.00 | 1.00 | 0.892 |
| BGE + FAISS | 0.45 | 0.75 | 0.80 | 1.00 | 0.621 |
| BM25 + BGE（RRF） | 0.55 | 0.90 | 1.00 | 1.00 | 0.725 |

在1024/128设置下，BM25仍是最优检索器。混合检索的Recall@1和MRR@10均低于BM25，因此不能声称RRF带来了总体提升。原因是这批题包含较多文件年份、版本号、学分数和政策术语，BM25的精确匹配已经很强；BGE排错的结果经RRF融合后会稀释BM25的高位优势。

## 文件说明

- `t4_metrics.csv`：三种检索器的正式指标。
- `t4_metrics_1024_128.png`：Recall@k与MRR@10对比图。
- `t4_rankings.jsonl`：20题、三种检索器的逐题排序。
- `t4_bge_cases.md`：5条BGE占优和5条BM25占优查询，含两路top-3与原因分析。
- `t4_bge_candidate_probe.json`：额外语义改写诊断题的完整排序；不计入正式指标。
- `t4_diagnostics.json`：首次证据名次与top-5完整覆盖诊断。
- `qa_set_1024_128.jsonl`、`qa_mapping_1024_128.json`：原评测题到新分块编号的映射及核对记录。
- `run_metadata.json`：模型、索引和分块等运行信息。
