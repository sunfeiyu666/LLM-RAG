# T5：1024/128分块实验说明

本次T5建立在同批1024/128分块的T4最优检索器BM25之上。每题先召回top-5，再比较直接取top-3、规则重排取top-3和Cross-Encoder重排取top-3；三种策略均测试压缩前与压缩后，共20题、120条回答。

规则重排依据问题中的标题、年份与文档元数据调整顺序；模型重排使用本地`bge-reranker-base`。内容压缩按问题词的自信息量保留相关句子。答案由本地`qwen3:4b-instruct`生成，准确性和引文支撑度均按0—2分逐题核对。

## 结果汇总

| 策略 | 压缩 | 平均Context token | 准确性 | 引文支撑度 | 重排延迟（秒） | 端到端延迟（秒） |
|---|---|---:|---:|---:|---:|---:|
| 直接top-3 | 否 | 1861.35 | 1.75 | 1.80 | 0.000 | 14.42 |
| 直接top-3 | 是 | 697.80 | 1.55 | 1.50 | 0.000 | 9.67 |
| 规则重排 | 否 | 1738.45 | 1.75 | 1.80 | 0.0001 | 12.38 |
| 规则重排 | 是 | 675.70 | 1.50 | 1.50 | 0.0001 | 9.31 |
| Cross-Encoder重排 | 否 | 1735.60 | 1.80 | 1.80 | 1.528 | 14.48 |
| Cross-Encoder重排 | 是 | 665.45 | 1.55 | 1.55 | 1.494 | 10.91 |

## 结论

未压缩时，Cross-Encoder准确性为1.80，比直接top-3和规则重排的1.75高0.05，但每题额外增加约1.53秒重排时间，提升较小。规则重排几乎没有计算开销，但平均准确性没有超过直接top-3。因此，本次重排只有Cross-Encoder带来轻微质量提升，是否值得取决于系统是否能接受额外延迟。

压缩后，直接、规则和Cross-Encoder的Context token分别减少约62.5%、61.1%和61.7%，端到端延迟分别减少约32.9%、24.8%和24.7%；但准确性分别下降0.20、0.25和0.25。典型错误是压缩删除了与问题相邻但关键词较少的限制条件，例如把GPA 3.0条款压掉后只保留综合测评80分，或者遗漏“按前一学期所在专业审核”。因此，这次压缩节省了大量token和部分时间，但以可见的答案质量下降为代价，不能说是无损优化。

- `t5_quality_summary.csv`：六组质量评分汇总。
